# Chat de compra

Comprador y organizador pueden intercambiar mensajes sobre una compra.

Depende de [PURCHASES](PURCHASES.md).

- [ ] MSG-01 Implementar historial de mensajes con permiso para ambos participantes.
- [ ] MSG-02 Guardar mensajes no vacíos con autor y fecha, con el mismo control de acceso.
- [ ] MSG-03 Mostrar el historial desde el detalle del comprador y desde la lista de ventas.
- [ ] MSG-04 Enviar mensajes y actualizar la conversación al volver a la pantalla.
- [ ] MSG-05 Probar ida y vuelta entre roles y rechazo a una tercera identidad.
