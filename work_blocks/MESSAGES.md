# Chat de compra

Comprador y organizador pueden intercambiar mensajes sobre una compra.

Depende de [PURCHASES](PURCHASES.md).

- [x] MSG-01 Implementar historial de mensajes con permiso para ambos participantes.
- [x] MSG-02 Guardar mensajes no vacíos con autor y fecha, con el mismo control de acceso.
- [x] MSG-03 Mostrar el historial desde el detalle del comprador y desde la lista de ventas.
- [x] MSG-04 Enviar mensajes y actualizar la conversación al volver a la pantalla.
- [x] MSG-05 Probar ida y vuelta entre roles y rechazo a una tercera identidad.
