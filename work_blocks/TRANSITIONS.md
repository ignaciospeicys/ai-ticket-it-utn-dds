# Cancelación y uso

El sistema permite cancelar o marcar como utilizada una compra cuando corresponde.

Depende de [PURCHASES](PURCHASES.md).

- [x] STA-01 Implementar cancelación de una compra pendiente no utilizada y anterior al evento.
- [x] STA-02 Implementar reembolso simulado de una compra confirmada dentro del mismo plazo.
- [x] STA-03 Probar que cancelar dos veces no devuelve cupo extra y rechazar cancelaciones tardías o de entradas usadas.
- [x] STA-04 Mostrar confirmación y resultado de la cancelación en el detalle del comprador.
- [x] STA-05 Permitir que el organizador dueño marque una compra confirmada como utilizada en la fecha permitida.
- [x] STA-06 Conectar la acción de uso en la pantalla de ventas y verificar el estado en ambos roles.
