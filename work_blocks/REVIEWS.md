# Reseñas

Una reseña válida aparece en los eventos posteriores del organizador y afecta su puntaje.

Depende de [TRANSITIONS](TRANSITIONS.md), [CATALOG](CATALOG.md).

- [x] REV-01 Validar que solo el comprador de una entrada usada de un evento finalizado pueda reseñar una vez.
- [x] REV-02 Guardar puntaje y comentario y devolver el promedio del organizador al catálogo.
- [x] REV-03 Mostrar el formulario de reseña desde una compra elegible.
- [x] REV-04 Mostrar reseñas de eventos previos en el detalle de otros eventos del organizador.
- [x] REV-05 Probar con una compra usada de prueba y verificar que la reseña cambia el orden por puntaje.
