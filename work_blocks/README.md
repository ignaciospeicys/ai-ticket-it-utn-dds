# Work blocks

Cada archivo tiene un objetivo, una dependencia y tareas numeradas de aproximadamente cinco minutos de trabajo activo. Seguir el orden de [index.md](index.md).

Marcar la tarea en curso con 🔨 y cambiar a `[x]` al verificarla. Si no entra en cinco minutos, dividirla en subtareas con criterio de cierre propio. Las esperas de instalación, descarga o arranque del simulador se contabilizan aparte.

Mantener las decisiones en [ARCHITECTURE.md](../ARCHITECTURE.md). Para cada regla de negocio, dejar una nota breve cuando una propuesta de IA requiera corrección o revisión manual. Esas notas sirven para la reflexión del video.
